# Cadre — Explorateur de films

Cadre est une mini-application responsive qui présente une sélection de films sous forme de cartes. Elle permet de rechercher par titre, genre ou année, de filtrer par genre et de sauvegarder ses films favoris dans le navigateur.

## Lancer l'application

Ouvrez `movie-explorer.html` dans un navigateur récent. Aucun serveur, compte, clé API ou paquet à installer n'est requis.

## Fonctionnalités

- Cartes de films avec affiche graphique, genre, année et note.
- Recherche instantanée par titre, genre et année.
- Filtres par genre et vue des favoris.
- Favoris persistants grâce à `localStorage`.
- Mise en page responsive et états accessibles pour les filtres et favoris.

## Personnaliser

Les données de démonstration se trouvent dans le tableau `films` du script de `movie-explorer.html`. Ajoutez ou modifiez les objets de ce tableau pour changer la sélection. Les affiches sont des fonds CSS, sans images ni API distantes.

## Déploiement

Le fichier est statique et peut être publié sur tout hébergement de sites statiques (par exemple GitHub Pages, Netlify ou Cloudflare Pages). Aucune étape de compilation n'est nécessaire. Le déploiement public n'a pas été effectué dans le cadre de cette création.
